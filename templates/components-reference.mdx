## Quick index

| Component | Use for |
| --- | --- |
| `<Note>` | Neutral context |
| `<Tip>` | Best practice / shortcut |
| `<Warning>` | Danger / legal / destructive |
| `<Info>` | Metadata (target, CVSS, tag) |
| `<Check>` | Success / flag captured |
| `<Steps>` | Kill chain, ordered process |
| `<Accordion>` | Collapse long output |
| `<AccordionGroup>` | Stack related accordions |
| `<Tabs>` / `<Tab>` | Alternatives (OS, protocol, tool) |
| `<CardGroup>` / `<Card>` | Landing pages, category jumps |
| `<Frame>` | Wrap screenshots with a caption |
